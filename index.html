Ключевые задачи и реализация
  • Разработал с нуля нативное Android-приложение — центральный узел университета для студентов (доступно в RuStore).
  • Спроектировал модульную архитектуру на базе MVVM с использованием Jetpack Compose для современного реактивного UI и Dagger для внедрения зависимостей.
  • Реализовал гибридное ядро: кастомный WebView с двусторонней связью через gRPC и JavaScript-интероп, что позволило фронтенду вызывать нативные методы (NFC, камера) и получать результаты обратно.
  • Внедрил нативные функции, недоступные или плохо работающие в браузере:
    • NFC-модуль для эмуляции студенческого билета — проход в здания университета касанием телефона.
    • Сканирование QR-кодов для мгновенной отметки посещаемости пар.
    • Авторизация через OAuth 2.0 с бесшовной поддержкой сессий в WebView и нативных компонентах.
  • Добавил систему пуш-уведомлений об изменениях в расписании и событиях университета.

📱 Проект: Pitanil — Мобильное приложение для мониторинга здоровья
  • Стек: Android, WearOS, Jetpack Compose, Health Connect (Android Health SDK), Samsung Health SDK, gRPC/Bluetooth, MVVM
Ключевые задачи и реализация
  • Разработал нативное Android-приложение для пациентов, позволяющее отслеживать динамику заболеваний на основе данных с носимых устройств (умные часы, браслеты).
  • Создал отдельную версию приложения для WearOS, оптимизированную для работы на экранах умных часов с учётом ограничений по энергопотреблению и производительности.
  • Интегрировал Android Health SDK (Health Connect) для сбора и агрегации данных о физической активности, пульсе, сне и других метриках с различных устройств.
  • Реализовал модуль связи с носимыми устройствами через Samsung Health SDK, обеспечив стабильную синхронизацию данных в реальном времени между смартфоном и часами.
  • Разработал систему мониторинга показателей:
    • Автоматический сбор данных о вариабельности сердечного ритма (HRV), шагах, калориях и качестве сна.
    • Алгоритмы отслеживания отклонений от индивидуальной нормы пациента (например, резкое повышение пульса в покое).
    • Формирование графиков динамики состояния для врача и пациента.
  • Обеспечил безопасную передачу медицинских данных на сервер с использованием шифрования и соблюдением требований к хранению чувствительной информации.
  • Разработал пользовательский интерфейс на Jetpack Compose для мобильной версии и Compose для WearOS, сделав акцент на крупных элементах управления и читаемости показателей.
Результаты и метрики
  • Приложение опубликовано в RuStore (доступно для скачивания).
  • Обеспечил поддержку популярных моделей умных часов (Samsung Galaxy Watch series и другие на WearOS).
  • Сократил время сбора данных о пациенте для врача с нескольких минут до автоматического мониторинга 24/7.
  • Повысил точность отслеживания рецидивов за счёт непрерывного сбора метрик, а не разовых измерений.
